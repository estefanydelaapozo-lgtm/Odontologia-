# Instalación

Sigue los pasos actualizados para generar claves, crear el archivo `.env`, iniciar Docker, ejecutar el proyecto localmente y diagnosticar errores en [GUIA_EJECUCION_LOCAL.md](./GUIA_EJECUCION_LOCAL.md). La guía principal y los comandos mínimos también están en [README.md](./README.md).

No uses las cuentas de demo con datos reales. El archivo `backend/.env` y sus credenciales locales no forman parte del ZIP. Revisa [REQUIREMENTS_CHECKLIST.md](./REQUIREMENTS_CHECKLIST.md) para distinguir los requisitos implementados de los pendientes de validación.
